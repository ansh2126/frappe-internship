# Python OOP Mini Catalogue

This project demonstrates basic Python Object-Oriented Programming concepts.

## Concepts Covered

- Classes and Objects
- `__init__` constructor
- Properties using `@property`
- Decorators
- Exception handling
- Python modules

## Project Structure

- `catalogue.py` - Contains Product and Catalogue classes.
- `main.py` - Imports the classes and runs the catalogue.

## Features

- Add products to the catalogue.
- Store product name, price, and quantity.
- Validate price and quantity.
- Display available products.
- Handle errors using exceptions.
- Log catalogue actions using a decorator.
